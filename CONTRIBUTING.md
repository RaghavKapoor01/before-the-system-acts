# Contributing / Feedback

This framework is under active development. Feedback from practitioners in AI governance, risk, compliance, and business analysis is genuinely welcome.

## Ways to contribute

- **Open an issue** if you've applied one of the templates and found a gap, ambiguity, or improvement — real-world use cases are the most valuable feedback this project can get.
- **Open a pull request** if you'd like to propose a specific wording change, a new example, or an adaptation of a template for a different regulatory context (a jurisdiction other than the UAE, for instance).
- **Reach out directly** via [LinkedIn](https://linkedin.com/in/raghavkapoor01) if you'd prefer to discuss before submitting anything formally.

## What this project is looking for

- Concrete examples of applying the Decision Boundary Specification, Escalation Criteria, or Human Review Acceptance Checklist to a real (anonymised) system
- Critique of the three-element framework (execution boundary, intervention threshold, evidence standard) — where it holds, where it doesn't
- Adaptations for other regulatory contexts beyond the UAE/CBUAE focus of Part 4
